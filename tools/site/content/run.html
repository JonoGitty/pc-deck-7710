Two ways in, neither needs hardware.

The PC deck

python legacy/server.py

Opens 127.0.0.1:7710. Play music anywhere — Spotify, YouTube, a game — and it lights up on its own. Windows, because it captures WASAPI loopback and Windows media metadata.

Preview a panel you have not bought

sh tools/serve.sh

Compiles core/ to WASM and emulates any panel: grid size, level count, dot shape, illumination colour. Same C the firmware runs, so it is what the glass does rather than an impression of it.
